# 🖥️ My Home Lab

Welcome to my Home Lab repository! This is where I experiment, learn, and build projects. My home lab is a personal environment designed to simulate real-world workflows and scenarios, enabling me to deepen my understanding of various technologies and tools.

## 🧠 Why a Home Lab?

My Home Lab is a sandbox environment where I can break things, fix them, and learn from the process. It allows me to:
- Practice and refine my technical skills
- Explore new tools and technologies
- Prepare for real-world scenarios in a risk-free setting
- Deploy services and applications without spending much money

## 📚 Learning and Experimentation

This lab is a continuous work in progress. Here’s what I’m currently focused on:
- **Data Integration**: Exploring ways to connect different data sources and streams
- **Cloud-Native Applications**: Deploying and managing cloud-native applications in a simulated cloud environment
- **System Development**: Nothing specific at the moment, I'm just interested in learning how to build tools and technologies to help with systems management

## 🔨 Tools & Technologies

I'm always learning and picking up new tools, below is a curated list of what I currently support:

### ☁️ Virtualization and Containerization
- **Virtualization**: Proxmox VE for managing virtual machines
- **Containers**: Docker for containerised applications

### 🛡️ Security and Networking
- **Security**: UFW and CrowdSec to harden my infrastructure with plans of adding pfSense and managed switches for VLANs
- **SSL/TLS**: Caddy as a reverse proxy with automatic SSL/TLS certifications 

### 🔍 Observability
- **Monitoring**: Prometheus, Grafana, Grafana Loki

### 🛠️ System Administration
- **Operating Systems**: Ubuntu, Debian
- **Automation**: Bash and PowerShell scripting
